# Excel Project
This project focuses on analysing total sales amount of Vrindavan Stores(Cloth Store) of April,2022
1. Project Title/Headline
    The title for this dashboard is 'Sales Analytics'.

2. Purpose
   This dashboard has been created to solve following queries:-
   a) Which month has highest amount of sales?
   b) Who has purchased more,Men or Women?
   c) To know the status of order,whether the orders are cancelled,delivered,refunded or returned?
   d) To know the top 5 most purchasing state?
   e) To know which age group of people buys more clothes?
   f) To know which Delivery channelhas helped more to Vrinda Store to sell their clothes?

3.Tech Stack
  This dashboard has only been created using Excel,no other tools has been used.

4. Data Source
   I got this data from Youtube.

5. Insights
   By this dashboard,we have got following insights-
   a) March is the month with most no. of Sales.
   b) Women has bought more clothes from store as compared to Men.
   c) Maharashtra is the state with most no. of sales.
   d)Amazon is the channel which helps Vrinda Store the most to sell their products.
